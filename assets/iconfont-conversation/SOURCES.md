# Icon sources

The conversation toolbar icons were selected from the public linear icon results
on [Iconfont](https://www.iconfont.cn/) on 2026-07-28 and stored locally so the
prototype does not depend on a remote runtime asset.

- `search.svg`: Iconfont search result for “搜索”
- `filter.svg`: Iconfont search result for “筛选”
- `sort.svg`: Iconfont search result for “排序”
- `group.svg`: Iconfont search result for “关联”
- `list.svg`: Iconfont search result for “列表”
- `download.svg`: Iconfont search result for “下载”

The SVG markup was normalized to a shared `1024 × 1024` view box and a neutral
single-color fill for use in the EviaBot admin prototype.
